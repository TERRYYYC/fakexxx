# v0.1.0 版本说明

状态：**Release Candidate**。发布代码已合入 main，自动门禁和独立代码审阅已有证据；
最终 APK 尚未在目标手机完成安装与验收。公开 APK 发布还受“迁移到受控 Release key
并批准升级方案”阻塞，因此现在不能创建正式 Release。

## 本版内容

- 千万游负责位置档案，通过 System Mock 或合格的 root + Xposed/LSPosed Hook 环境应用。
- Auto 负责发现、配对、能力协商、档案选择和 Provider 侧执行请求。
- 新增可信计数、耗尽后停止、跳过 legacy GPS、`SERVICE_RECYCLED` 可见终态。
- 新增配对/撤销确认、安全重跑和 Mock AppOp 提示。
- Binder 边界验证包身份并返回明确执行结果，不把“能连接”误判为“已执行”。
- Release 构建排除 debug-only collector，并提供构建、安装和证据校验脚本。

## 安装与首次启动

1. 导出或备份位置档案，并记录当前数据库 schema/version。
2. 用根 README 的校验安装脚本先安装千万游，再安装 Auto。
3. 首次启动后验证 schema 健康和每个必要档案。
4. System Mock 需在开发者选项选择千万游，并在目标 Release 环境验证配置发布通道。
5. Hook 需 root，且在 Xposed/LSPosed 中启用模块和目标作用域。
6. 在千万游设置页配对 Auto，用真实档案完成目标模式验收。

覆盖安装保留数据目录，但不保证 App 内数据库迁移无损。Android 报签名不兼容时停止，
不要用卸载来绕过，除非明确接受数据删除。

## 剩余门禁

- 公开发布前迁移到获批受控 Release key；公开仓库的 GitHub Release 属于公开分发。
- 全部通过后才可把本页改为 `released`、创建 `v0.1.0` tag 和正式 Release。
